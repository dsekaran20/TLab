# முத்தும் பாடலும்

சங்ககாலத் தமிழகம் ஊக்கமாக அமைந்த சிறிய ஒரே பக்க செயற்பாட்டு முன்மாதிரி. வீரர் கொற்கைக் கடற்கரையிலிருந்து மதுரையின் பாண்டிய அரசவைக்கு முத்துப் பையும் குறும் பாடலும் கொண்டு செல்லும் இளவன் என்ற இளம் தூதனாக விளையாடுகிறார்.

ஆறு காட்சிகள், ஒவ்வொரு காட்சிக்கும் மூன்று தேர்வுகள், நான்கு அளவுகோல்கள்: நற்பெயர், முத்துகள், தெம்பு, பாடல் அறிவு. ஆறு வகை முடிவுகள் உள்ளன.

## கோப்புகள்

```
pandya-prototype/
├── index.html      # பக்க அமைப்பு மற்றும் UI உரை
├── styles.css      # பனை ஓலை உணர்வு கொண்ட காட்சி வடிவமைப்பு
└── game.js         # காட்சிகள், தேர்வுகள், அளவுகோல்கள், முடிவுகள்
```

இது முழுக்க static HTML / CSS / JavaScript. build step, backend, framework எதுவும் இல்லை. தமிழ் எழுத்துருக்கள் Google Fonts CDN வழியாக ஏற்றப்படுகின்றன.

## உள்ளூரில் இயக்க

```bash
cd pandya-prototype
python3 -m http.server 8765
# பிறகு http://localhost:8765/index.html திறக்கவும்
```

## வடிவமைப்பு குறிப்புகள்

- **மொழி:** UI, கதை, தேர்வுகள், அளவுகோல்கள், முடிவுகள் அனைத்தும் தமிழில் மாற்றப்பட்டுள்ளன.
- **பாணி:** மணல் நிறம், ஆழ்ந்த நீலம், முத்து வெள்ளை, மங்கிய பொன், பனை ஓலை அமைப்பு.
- **அணுகல்தன்மை:** keyboard மூலம் இயக்கக்கூடிய பொத்தான்கள், focus rings, `aria-live` narrative பகுதி.
- **குறிப்பு:** “சங்ககாலத் தமிழகம் தூண்டுதலாக அமைந்த வரலாற்றுப் புனைவு முன்மாதிரி” என்ற disclaimer UI-யில் உள்ளது.
